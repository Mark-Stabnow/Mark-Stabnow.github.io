FEATURED PROJECT

Warehouse Inventory

CS 360 original · CS 499 enhancements

From an Android app to a shared inventory system.

I started with the inventory app I built in CS 360. For my capstone, I kept its item and stock workflows and expanded them into a web application.

The current source includes a React and TypeScript interface, an Express API, PostgreSQL storage, and an offline queue for stock changes. Milestone Four adds inventory import tools and database checks.

  • React + TypeScript
  • Express
  • PostgreSQL
  • Docker
