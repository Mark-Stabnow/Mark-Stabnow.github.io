Milestone One code review

The Warehouse Inventory App began as an Android project from CS 360. The original application included account creation and login, an inventory grid, item creation and deletion, quantity changes, and zero inventory alerts. The code review used that working version as the starting point for the capstone.

What the review found

The Android screen classes combined UI work with validation, database calls, and quantity rules. Persistence used hand written SQLite queries. Credentials were stored without the protections I would want in a shared application. Search and sort worked over the loaded list, quantity updates overwrote the previous value, and there was no tested schema migration path or automated test suite.

Those problems became the basis for the three enhancement areas instead of being hidden. Software design focused on separating the client, API, and database responsibilities. Algorithms focused on exact SKU lookup, prefix search, lowest stock selection, and the cost of maintaining indexes. Databases focused on preserving data, stock history, constraints, migrations, and reconciliation.
