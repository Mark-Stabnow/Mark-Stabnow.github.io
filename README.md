# Mark Stabnow CS 499 ePortfolio

This repository hosts my CS 499 capstone ePortfolio and the Warehouse Inventory App artifacts used for the three enhancement areas.

The site is intentionally small: static HTML and CSS at the repository root, with no JavaScript framework, analytics, external fonts, or site generator required. The existing `artifacts/milestone-four` directory contains the original Android source, PWA baseline, enhanced PWA, and verification evidence.

Open `index.html` locally or visit the GitHub Pages site after the branch is merged into `main`.
